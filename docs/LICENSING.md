# Licensing and support model

## Project code

Project-owned source code is licensed under the Mozilla Public License 2.0 (MPL-2.0). The full license is in the repository [LICENSE](../LICENSE). Files or directories with their own license notices keep those terms. Third-party components are not relicensed by the project license.

For Android, the release includes LibRaw 0.22.2 under its selected CDDL 1.0 terms, with upstream CDDL/LGPL notices and source archive. Bundled Geist fonts retain the SIL Open Font License, and Lucide icons retain the ISC license. Their existing notices remain with the Android source and APK.

Windows desktop includes a hold-to-remove control adapted from React Bits Hold Button (https://reactbits.dev/micro/hold-button). Interaction mechanics were retained; visuals were restyled for Quiet Darkroom. Verify the upstream React Bits license/attribution again before any public source snapshot that ships that file.

## Free core and optional support

The converter core remains free to use. Optional voluntary support through Buy Me a Coffee is planned. Contributions will not unlock product features, and the support link will be added after the creator page is set up.

## Possible paid features

Paid features may be considered later as a separate module or set of files. MPL-2.0 permits a larger work to use different terms for separate, non-covered material, while changes to MPL-covered files must remain available under MPL-2.0 to recipients when distributed. Keep paid files separate from MPL-covered code and do not copy MPL-covered implementation into them. Review the exact module boundary and any bundled dependencies before shipping a paid edition.

## Changing the license later

The maintainer may choose different terms for future code they own. A later license change does not remove the MPL-2.0 rights already granted to recipients for code released under MPL-2.0. Contributions from other copyright holders may only be relicensed if their rights allow it or they separately agree. Establish contribution terms before accepting outside code if future relicensing is important.

This file records the project's current licensing and support decisions; the license texts and third-party notices control their respective code and assets.
